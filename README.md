# ArrayList Simulator (Java)

An educational project that simulates some of the basic functionalities of Java's `ArrayList`.
## Purpose
This project was developed for learning and practicing:
- Object-Oriented Programming (OOP) concepts in Java
- Working with arrays
- Understanding how dynamic array-based data structures work
## Note
This is a practice project created for educational purposes and is not intended to replace Java's built-in `ArrayList`.
